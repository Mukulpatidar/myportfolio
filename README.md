## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Type Checking & Linting
```bash
npm run type-check
npm run lint
```

### 4. Build for Production
```bash
npm run build
npm run start
```
